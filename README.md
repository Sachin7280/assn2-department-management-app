# ASSN2 Department Management App

A complete Department Management Android Application developed for 4th Semester App Development Project.  
This application helps departments manage student attendance, events, profiles, and alumni information in a smart and organized way.

---

## 📱 Features

### 👨‍🎓 Student Module
- Student Registration & Login
- Student Profile Management
- Attendance Tracking
- Event Notifications
- Department Updates

### 🏫 Department Module
- Manage Student Attendance
- Upload Department Events
- Add Notices & Announcements
- View Student Details

### 🎉 Event Management
- Create Department Events
- Event Details & Schedule
- Event Participation Information

### 🧑‍💼 Alumni Module
- Alumni Registration
- Alumni Information Management
- Alumni Networking Support
- Passout Year & Contact Details

---

## 🛠️ Tech Stack

- Android Studio
- Java / Kotlin
- XML
- Firebase Authentication
- Firebase Realtime Database / Firestore
- Material UI Components
